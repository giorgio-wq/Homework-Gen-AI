# Caso Legal Studio

Create a polished, responsive, multi-page website for an independent Italian law firm called “Studio Legale Caso”.

IMPORTANT: This must be a true multi-page website, not a one-page scrolling website.

Create these four separate routes:

Home: /

About Us: /about

Services: /services

Contact: /contact

The website is initially being developed in English. However, structure all textual content in a centralized and reusable way so that an Italian version and an EN/IT language switch can be added easily in a later iteration. Do not display an unfinished language selector yet.

DESIGN DIRECTION

Use Advancy’s website as a general visual reference for its editorial feeling, large typography, generous whitespace, strong page transitions and consulting-firm aesthetic.

Do not copy Advancy’s content, layouts, branding or individual design elements.

Use modern Italian and European professional-services websites as inspiration. The result should feel like a boutique strategy consultancy adapted to a law firm.

Suggested visual direction:

Sophisticated and minimal

Editorial layout

Large, confident typography

Strong grid system

Generous whitespace

Off-white or warm ivory backgrounds

Deep navy or near-black primary color

Muted burgundy, terracotta or copper accent color

Refined typography pairing

Subtle lines and geometric details

Restrained, elegant animations

Smooth but fast page transitions

Avoid generic legal-sector clichés such as:

Gavels

Scales of justice

Courthouse columns

Law books used as decorative stock imagery

Golden gradients

Excessive dark-blue corporate templates

Generic AI-generated office images

Fake testimonials

Fake awards

Fake statistics

For the initial version, create a simple typographic wordmark reading “Studio Legale Caso”. It should be easy to replace later with a custom logo.
